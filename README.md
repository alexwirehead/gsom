## 💬 Пыщь-коммиты

В репозитории живёт скилл для Claude Code — **`pyshch-commit`**. Он пишет коммиты в стиле платформы: смешные, абсурдные, но честные. Заголовок всегда говорит, что на самом деле изменилось, поэтому `git log --oneline` и `git bisect` остаются полезными. Шутки живут в хвосте, теле и трейлерах.

```
perf(glagne): кешировать ширину летающих надписей — без layout thrash

- tick() больше не читает offsetWidth у каждой надписи на каждом кадре
- ширина замеряется один раз и сбрасывается только при смене текста
- надписи летают так же абсурдно, просто браузер больше не потеет

Synergy: +146%
Onotole-Verdict: одобряе
```

### Как пользоваться

Откройте репозиторий в [Claude Code](https://docs.claude.com/en/docs/claude-code/overview) и скажите **«закоммить»**. Скилл лежит в `.claude/skills/pyshch-commit/` и подхватывается автоматически — ставить ничего не нужно.

Дальше он сам:
1. посмотрит застейдженный дифф и историю коммитов (а если ничего не застейджено — спросит, что включить);
2. напишет сообщение по Conventional Commits со скоупами платформы;
3. прогонит его через валидатор;
4. покажет вам и закоммитит только после вашего «го».

### Уровни абсурда

| Уровень | Название | Как попросить |
|:---:|---|---|
| 1 | Офисный пыщь | «закоммить, но потише» |
| 2 | Синергия | «закоммить» — по умолчанию в этом репо |
| 3 | Стопицот | «закоммить, жги» |

Уровень по умолчанию задаётся строкой `pyshch-commit: level N` в `CLAUDE.md`.

### Валидатор

Скилл не даст платформе опозориться. Перед коммитом сообщение проверяет `check_message.py`:

- ❌ заголовок длиннее 72 символов — шутливый хвост уезжает в тело;
- ❌ не Conventional Commits или нет пустой строки после заголовка;
- ❌ фейковые `Co-authored-by` / `Signed-off-by` / `Reviewed-by` — GitHub может привязать их к чужому аккаунту;
- ❌ мат и туалетный юмор — у нас семейная синергия;
- ⚠️ `BREAKING CHANGE` — semantic-release поднимет мажорную версию, поэтому для космических шуток есть трейлер `Cosmic-Change:`.

Валидатор работает и без Claude:

```bash
python3 .claude/skills/pyshch-commit/scripts/check_message.py сообщение.txt
```

### Безопасные трейлеры

`Onotole-Verdict: одобряе` · `Synergy: +146%` · `Pyshch-Level: !!!11адинадин` · `Cosmic-Change: вселенная теперь происходит из бороды Онотоле` · `Krevedko-Approved: yes` · `Spam-Count: spam, spam, eggs and spam`

### Хочу так же в своём репо

Скопируйте папку `.claude/skills/pyshch-commit/` в свой репозиторий — или в `~/.claude/skills/`, чтобы скилл работал во всех проектах. В англоязычных репо он переходит в English mode: Монти Пайтон работает как есть, а «пыщь!!!11» становится «pew pew!!!11».

## ❓ FAQ

**Это продакшн-реди?**
Это продакшн-рейди. Отличие в одну букву, а в сумме уверенности на 146% больше.

**Почему SLA 146%?**
Потому что 100% — это для тех, кто не верит в синергию.

**Почему нет звука?**
Нажмите кнопку на стартовом экране. Если звук всё равно не идёт, проверьте, не нажата ли кнопка 🔇.

**Почему котэ деплоит в прод?**
Потому что котэ прошёл ревью у Онотоле, а вы нет.

**Можно использовать платформу в реальном энтерпрайзе?**
Можно показать её на стендапе. Синергия гарантирована.

**Почему коммиты такие смешные?**
Потому что история git — это тоже глагне. Но заголовок у каждого коммита честный, так что смешно и полезно одновременно.

**Кто такой Онотоле?**
Легендарный персонаж рунета нулевых: человек, который знает всё. Мы относимся к нему с огромным уважением и исключительно в одобряющем ключе.
