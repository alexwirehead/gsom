# ПЛАТФОРМА-ИИ-ПЛАТФОРМА

Сайт-шутка в стиле Упячки: один самодостаточный файл `index.html`. Полная спецификация лежит в `docs/SPEC.md`, прочитай её перед любыми изменениями.

## Жёсткие правила
- Результат — **один HTML-файл без внешних запросов**: без CDN, шрифтов из сети, картинок и аудиофайлов. Графика — CSS, эмодзи и инлайн-SVG. Звук — Web Audio, речь — speechSynthesis.
- Звук запускается только после клика по кнопке стартового дисклеймера (`#go` или `#calm`), контекст создаёт и будит только `unlockAudio()`. Любая новая звуковая функция начинается с `if (!live()) return;`.
- Офисный режим `body.calm`: CSS-анимации гаснут сами, любое движение из JS обязано проверять `calm`. Блок `.serious` в дисклеймере остаётся серьёзным (SPEC §12).
- Соблюдать лимиты динамических элементов (SPEC §9). Всё, что создаётся в DOM, должно либо удаляться по таймеру, либо обрезаться по количеству.
- Проверять на трёх вьюпортах: 1440×900, 390×844, 844×390. Перед коммитом — `npm test` (статика + Playwright на трёх экранах, SPEC §14); новая фича — новый тест в `tests/`.
- Вспышки не чаще 3 раз в секунду.
- Лор: без политиков и частных лиц, без «выпей йаду» и «убейся апстену», без рисования чужих персонажей. Онотоле — только канонический хвалебный мем, без выдуманных цитат (SPEC §11).

## Где что
- Тексты и мемы — константы в начале `<script>` (SPEC §5). Новые мемы добавляются туда, логику трогать не нужно.
- Генератор платформ — `genPlatform()`, олбанский — `olbanize()`.
- Эффекты: `boomAt`, `beam`, `stamp`, `makeWin`, `interrupt(kind)`, `otake`.
- Музыка: УПЧК-амп — `ampPlay(i)`/`ampStop()`, треки в `TRACKS` (SPEC §6.12). Мелодии только свои.
- Режимы задаются классами на body: `popyach`, `silly`, `razupl`, `olb`, `shake`, `disco`, `calm` (офисный режим без анимаций, выбирается на стартовом дисклеймере).

## Коммиты
- Все коммиты в этом репозитории пишутся через скилл `pyshch-commit` (лежит в `.claude/skills/pyshch-commit/`), даже если просят просто «закоммить».
- pyshch-commit: level 2
- Скоупы: `glagne`, `onotole`, `generator`, `olbanian`, `audio`, `popups`, `interrupts`, `krevedko` (см. CONTRIBUTING.md).
- Перед коммитом сообщение проверяется валидатором скилла; коммит — только после подтверждения пользователя, без `--no-verify`, `--amend` и `push`.
- Никаких настоящих `BREAKING CHANGE:` ради шутки — для космических шуток трейлер `Cosmic-Change:`.

## Известный техдолг
См. SPEC §10. `offsetWidth` в `tick()` и конфликт `shake` с `popyach` исправлены; текст летающих надписей меняется только через `setFlyText()`. Главное из оставшегося: координаты клика в перевёрнутом режиме и неочищаемые таймеры.
