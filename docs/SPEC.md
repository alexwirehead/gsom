# ПЛАТФОРМА-ИИ-ПЛАТФОРМА — техническая спецификация

Вырвиглазный сайт-шутка в стиле Упячки про энтерпрайз-баззворды, ИИ-платформы, Онотоле, падонков и Монти Пайтона.
Документ описывает, как устроена текущая версия `index.html` (~1400 строк, ~105 КБ), чтобы дальше допиливать её через Claude Code.

---

## 1. Главные инварианты (не ломать)

1. **Один самодостаточный HTML-файл.** Весь CSS и JS инлайн, никаких внешних запросов: ни CDN, ни шрифтов, ни картинок, ни аудиофайлов. Файл пересылают в мессенджерах и открывают локально (`file://`).
2. **Всё рисуется и звучит из кода.** Графика — CSS, эмодзи и инлайн-SVG. Звук синтезируется через Web Audio API, речь — через `speechSynthesis`.
3. **Звук стартует только после жеста пользователя.** Браузеры блокируют autoplay, поэтому есть стартовый оверлей `#start` с дисклеймером о светочувствительности. По клику на одну из его кнопок создаётся `AudioContext` и запускаются все циклы.
4. **Респонсив:** десктоп, планшет (≤1000px), телефон (≤700px), телефон боком (высота ≤520px, landscape). Учитываются safe-area для айфонов с чёлкой.
5. **Хаос ограничен сверху.** У всех динамических сущностей есть лимиты (см. §9), иначе вкладка со временем умрёт.
6. **Контент-границы лора** (см. §11): без политиков, без частных лиц, без суицидальных падонковских мемов.

## 3. CSS

### 3.1 Переменные

```css
:root { --mq: 44px; --mqf: 26px; --gap: 12px; }
```

- `--mq` — высота бегущих строк. От неё отсчитываются позиции стикеров, панелей и кнопок, а JS читает её через `getComputedStyle` (функция `mq()`), чтобы окна и кнопка не залезали под строки.
- `--mqf` — кегль бегущих строк.
- `--gap` — отступ стикеров от верхней строки.

На телефоне (`≤700px`) переменные переопределяются: `32px / 18px / 6px`, боком — `30px / 16px / 4px`.

### 3.2 Слои (z-index)

| z | Что |
|---|-----|
| 2 | `#stage` — летающий текст (pointer-events: none) |
| 3 | `.center` — заголовок (pointer-events: none) |
| 4 | `.emoji` |
| 5 | `.marquee` |
| 6 | стикеры, панели, каменты, отзывы |
| 7 | `.pepyaka` |
| 8 | `.ufofly` — НЛО, пролетающее в такт музыке |
| 12 | `#popyach` |
| 13 | `.win` — окна Win98 |
| 14 | `.controls`, `.beam`, `.amp` — плеер УПЧК-амп |
| 15 | `.boom` — взрывы текста |
| 16 | `.stamp` — печати Онотоле |
| 25 | `.interrupt` — полноэкранные вставки |
| 30 | `#start` |

### 3.3 Состояния через классы на `<body>`

| Класс | Кто ставит | Эффект |
|-------|-----------|--------|

| `disco` | УПЧК-амп играет | кнопка «дисктоячка» подсвечена, эквалайзер прыгает, пепякомэн танцует быстрее |
| `shake` | `shake()` | тряска 3×150мс; перезапускается через reflow-трюк `void offsetWidth` |
| `calm` | кнопка `#calm` на стартовом дисклеймере | офисный режим: `animation: none !important` на body и всём внутри; `shake()` и пульс `.center` в JS молчат. Ставится один раз и не снимается |

### 3.4 Ключевые анимации

`bgmove` (полосатый фон), `run` (бегущие строки), `wobble` + `hue` (заголовок), `blink`, `silly`, `razupl`, `armL/armR/bounce` (пепякомэн), `up` (автоскролл креатиффа), `spin` (эмодзи), `boom`, `beamfade`, `stampin`, `ufo`, `zoom`, `shake`, `shakeflip` (тряска в перевёрнутом режиме), `hung` (дрожь зависшего окна), `winfall`/`winkick`/`winsync`/`winufo`/`winescal` (уходы окон), `eq` (эквалайзер плеера). Все они выключаются в `body.calm`.

### 3.5 Брейкпоинты

- **≤1000px:** уже панели, мельче шрифты.
- **≤700px:** панели «креатифф» и лог стоят двумя колонками под стикерами (`width: calc(50vw - 10px)`, `height: 22dvh`). Блок каментов скрыт, каменты подмешиваются в `.review`. Кнопки `.controls` выстроены в ряд с переносом над отзывами. Заголовок сдвинут вниз через `padding-top: 14dvh`.
- **landscape, высота ≤520px:** панели, каменты и отзывы скрыты, остаются заголовок, летающий текст и кнопки.

Высоты задаются в `dvh`, чтобы на мобильных адресная строка не ломала верстку.

## 4. JS: архитектура

Весь код живёт в одном IIFE без глобальных переменных. Сборщика нет, модулей нет, фреймворков нет.

### 4.1 Утилиты

```js
rnd(a, b)   // случайное float в [a, b)
pick(arr)   // случайный элемент
W(), H()    // размеры вьюпорта
mobile()    // W() <= 700
mq()        // текущее значение --mq в px
```

### 4.2 Глобальное состояние (внутри IIFE)

| Переменная | Назначение |
|-----------|-----------|
| `olb` | режим олбанского |
| `silly` | режим глупого деплоя (физика прыжков у летающего текста) |
| `ctx`, `muted`, `noiseBuf`, `unlocked` | аудио; `unlocked` — пустой буфер для iOS уже проигран |
| `amp` | состояние УПЧК-ампа: `{on, ti, step, next, timer, gain, parts, say, len, wake, slept, lastT, lastAt}` (§6.12) |
| `cnt` | счётчик «Платформ» |
| `flyers[]` | массив летающих надписей `{el, x, y, vx, vy, rot, vr, wob, ws, w}` (`w` — кеш ширины, §10.1) |
| `dodges` | счётчик уклонений кнопки ПОПЯЧЬСЯ |
| `li`, `ri`, `ti` | индексы ротации лога, отзывов, заголовков вкладки |
| `clopTimer` | интервал кокосового цоканья |

## 6. Подсистемы

### 6.1 Генератор платформ — `genPlatform()`

- В 82% случаев: `prefix()-CORE FOR`, где `prefix()` склеивает через дефис от 1 до 3 случайных `PRE`. Пример: «Квантово-1С-Нейро-data mesh для попячивания».
- В 18% случаев: `opsName()-платформа FOR`, где `opsName()` — перемешанные 3–6 элементов `OPS` + `"Ops"`. Пример: «MLGitVibeOps-платформа в Jira».
- Результат прогоняется через `maybeOlb()`.
- Согласование родов не делается, и это сознательный абсурд.

Где используется: летающий текст (24%), подзаголовок `#sub` (70%), лог (25% строк), речь (30%), каменты, окна, вставка «нечто совершенно иное».

### 6.2 Олбанский — `olbanize(s)` / `maybeOlb(s)`

Цепочка `replace`: `ться/тся→цца`, `жи/ши→жы/шы`, `ча/ща→чя/щя`, начальное `я→йа`, `-ая→-айа`, `-ов→-офф`, `о→а` (45%), `е→и` (25%). Работает и для заглавных.

`\b` не используется: в JS без флага `u` он не понимает кириллицу. Вместо него lookahead `(?=[\s,.!»-]|$)`.

Переключатель `#olb` меняет `olb`, переписывает `#h1a/#h1b` (GSOM ↔ ЖСОМЪ), сразу перегенерирует текст всех `flyers` и ставит печать. Тексты, уже сгенерированные в логе и каментах, остаются как были.

### 6.3 Летающий текст — `flyText()`, `makeFlyer()`, `tick()`

- Источники в `flyText()`: PHRASE 18%, UPCHK 22%, ONOTOLE 12%, PADONKI 10%, PYTHON 14%, MANAGER 10%, генератор 14%.
- Стартовое количество — `baseCount()` = площадь/45000, в диапазоне 12–34.
- Кегль 14–54px × `fontScale()` (0.5–1 от ширины 1200px).
- `tick()` вызывается на каждом `requestAnimationFrame`. Он двигает надписи через `transform: translate() rotate()`. При выходе за край надпись телепортируется на противоположную сторону и с вероятностью 35% меняет текст.
- В режиме `silly` работает гравитация: `vy += .6`, у пола отскок `vy = -rnd(8,18)`.
- Каждые 300мс всем надписям назначается случайный цвет.

### 6.4 Клики и курсор

- `pointerdown` по фону: луч поноса от случайного края экрана в точку клика, взрыв `boomAt()`, тряска, случайный звук, новая летающая надпись. Новые надписи добавляются, пока их меньше 40 на телефоне или 70 на десктопе. Клики по `#start`, `.controls`, `#popyach`, `.win` игнорируются.
- `pointermove`: след из коротких слов. Троттлинг 40мс для мыши и 90мс для тача.

### 6.5 Лучи поноса — `beam()`, `randomBeam()`, `otake()`

- `beam(x1,y1,x2,y2)`: `div.beam` с `left/top` в начале отрезка, `width = hypot`, `rotate(atan2)`, `transform-origin: 0 50%`. Анимация `beamfade` 0.6с, затем элемент удаляется.
- `randomBeam()` запускается вместе с половиной пердежей в `randomSound()`.
- `otake()`: 26 лучей в случайные точки прямоугольника `h1` с шагом 70мс, звук `laser()`, взрывы. На body ставится класс `razupl`, через 2с — печать «УГ РАЗУПЛОТНЕНО».

### 6.6 Печати Онотоле — `stamp(text, ok)`, `onotoleVerdict()`

- Одновременно на экране только одна печать: старые удаляются. Длительность 1.6с, звук `thud()` и тряска.
- `onotoleVerdict()`: в 60% случаев «ОДОБРЯЕ» (зелёная), иначе «НЕГОДУЕ»/«СЕРЧАЕ» (красная).
- Вызывается из `loopStamps()` каждые 14–26с, после «ВНЕДРИТЬ» в генераторе и после внедрения платформы из окна.

### 6.7 Окна Win98 — `makeWin()`, `randomPopup()`, `moreChaos()`

- `makeWin(icon, msg, btns, onAny, note)`. Лимит одновременно открытых окон: 3 на телефоне, 7 на десктопе. Сначала окно вставляется невидимым, чтобы измерить размер, потом позиционируется так, чтобы не вылезать за экран и бегущие строки.
- `randomPopup()`: в 28% случаев окно с только что сгенерированной платформой, иначе случайное из `STATIC_POPUPS`.
- Крестик не спасает: звук, взрыв «Ф БАБРУЙСК!/ХУЙС/ПОПЯЧТСО» и через 600мс новое окно.
- `placeWin(w)`: до 15 случайных позиций, первая, что не пересекает `.controls` и открытый плеер `#amp`. Если такой нет — последняя попытка.
- Игнор: через 7с без клика окно получает класс `hung` (серое, дрожит, в заголовке «(Не отвечает)», звук `robot()`), через 12с `winExit(w)` уводит его одним из `WIN_EXITS`: `fall` (попячтсо вниз), `kick` (Леониде пинает: ЭТО СПАРТА!!!), `sync` (ушло на синк, вылетает фраза из `MANAGER`), `ufo` (НЛО забрало окно), `escal` (эскалировано на Онотоле → печать), спам. Через 1.2с окно удаляется. Новый уход — строка в `WIN_EXITS` и CSS `.win.x-<kind>`.
- Расписание: первое окно через 2.5с после старта, затем каждые 7с с вероятностью 50%. Плюс цепные реакции из `moreChaos()`.

### 6.8 Кнопка ПОПЯЧЬСЯ — `placePop()`, `dodge()`

- Позиция задаётся только через `left/top` в px, без `transform`, и зажимается в пределах экрана с учётом `mq()`. На `resize` позиция пересчитывается.
- Уклонение: мышь — по `pointerenter`, тач — по `pointerdown` (с `preventDefault` и флагом `data-skip`, чтобы не засчитался последующий `click`). Каждое четвёртое уклонение пропускается, и кнопку удаётся нажать.
- По нажатию: переключение `body.popyach`, разворот скоростей всех надписей ×1.5 на 2с, пердёж задом наперёд `fart(true)`, речь. Текст кнопки меняется на ПОПЯЧЬСЯ/ОТПЯЧЬСЯ.

### 6.9 Внезапные вставки — `interrupt(kind)`

На экране одновременно только одна вставка. `loopInterrupts()` запускает их каждые 16–30с, первая — через 11с после старта.

| kind | Что | Звук | Длит. |
|------|-----|------|-------|
| `inq` | «НИКТО НЕ ЖДЁТ ИСПАНСКУЮ ИНКВИЗИЦИЮ!!!» | `chord()` дам-дам-ДАААМ | 2.4с |
| `diff` | «А теперь — нечто совершенно иное:» + сгенерированная платформа | `whistle()` | 3.2с |
| `spam` | экран, забитый словом СПАМ (60 или 160 спанов) | `honk()` | 2.4с |
| `gal` | «ГОЛАКТЕКО ОПАСНОСТЕ!!!», звёзды, пролетающий 🛸, затем печать «ОНОТОЛЕ СПАС ГОЛАКТЕКУ» | `theremin()` | 3.3с |
| `balet` | телевизор «503: СЕРВЕР УПАЛ. СМОТРИ БАЛЕТ!1» 🩰🦢 | `musicBox()` | 3.0с |
| `zoh` | флуд `floodText()` + мигающее «ПОТС ЗОХВАЧЕН!!!» + 10 лучей | `robot()` + `laser()` | 2.6с |

Каждая вставка также произносит свою фразу через `speak()`.

### 6.10 Глупый деплой

Переключает `silly`, класс на body и интервал `clop()` каждые 330мс (кокосы вместо копыт). При выключении надписям возвращается спокойная вертикальная скорость.

### 6.11 Панели

- **Лог:** каждые 450мс добавляется строка (75% из `LOG` по кругу, 25% `$ deploy <genPlatform()>`). Хранится не больше 30 строк. Прижат к низу через `flex-end`.
- **Каменты:** каждые 900мс случайный `[ник, камент]` (20% — «аффтар, а <платформа> будет?»). Не больше 14.
- **Отзывы:** каждые 2.8с, в 40% случаев камент, иначе `REVIEWS` по кругу.
- **Счётчик:** каждые 120мс `cnt += 1..999`, в 8% тиков показывается «СТОПИЦОТ».
- **Подзаголовок `#sub`:** каждые 2.2с (PYTHON 15%, ONOTOLE 15%, генератор 70%).
- **Заголовок вкладки:** ротация каждые 500мс.
- **Эмодзи:** 5 (телефон) или 10 (десктоп) крутящихся, каждый со своим интервалом перескока 0.7–2с.

### 6.12 УПЧК-амп — `ampPlay(i)`, `ampStop()`, `ampTick()`, `ampStep(t)`

- Окно `#amp` (класс `.win.amp`) статичное, живёт в HTML с `hidden`. Открывается кнопкой `#disco`, крестик и повторный клик по кнопке останавливают музыку и прячут окно. `makeWin()` считает лимит окон по `.win:not(.amp)`.
- Секвенсор с упреждением: `setInterval(ampTick, 25)` планирует все шаги, попадающие в ближайшие 120 мс, на `ctx.currentTime`. Шаг — шестнадцатая, длительность `60 / bpm / 4`.
- Партии парсятся из строк `TRACKS` (§5). Токены: нота `A4` (диезы `C#4`), аккорд `D4+F4+A4`, `-` тянуть предыдущую ноту, `.` пауза, `|` граница такта (игнорируется). Каждая партия зацикливается по своей длине.
- Трек играет `loops` раз (по умолчанию 2) по длине самой длинной партии, потом сам включается следующий. Кнопка «дисктоячка» стартует со случайного трека.
- Инструменты: `melody` — тип из `lead` (по умолчанию square), `bass` — `bassWave` (по умолчанию square; `reese: true` добавляет второй осциллятор на +1.2% для жирного баса), `chords` — короткий тихий square (скэнк), `drums` — `K` бочка (sine 150→40), `S` снейр и `h`/`o` хэты (общий `noise()` через фильтры), `fx` — `p` `pew()`, `u` `theremin()` + `.ufofly`, `z` `honk()`.
- Все ноты идут в отдельный `amp.gain`. `ampStop()` чистит интервал и гасит этот gain, чтобы уже запланированные ноты замолчали; следующий `ampPlay()` создаёт новый gain.
- На каждую долю `.center` чуть пульсирует через Web Animations API (без вспышек), фразы `say` произносятся по очереди раз в `sayEvery` тактов.
- Пока играет музыка, `loopSounds()` звучит в 15% случаев, а `loopSpeech()` молчит. Mute останавливает плеер.
- iOS. Контекст создаёт и будит только `unlockAudio()`: перед созданием ставит `navigator.audioSession.type = "playback"` (иначе Web Audio глушится беззвучным режимом), вызывает `ctx.resume()` и один раз проигрывает пустой буфер. `wake()` вызывает её на каждом `touchend`/`click` (capture), а `visibilitychange` будит контекст после сворачивания Safari. `ampPlay()` при спящем контексте сначала ждёт `resume()`. Если контекст уснул во время трека (`onstatechange` или `currentTime` стоит дольше секунды в `ampTick`), `ampSleep()` останавливает плеер, просит «ТЫКНИ ▶» и запоминает трек в `amp.slept`; когда контекст снова `running`, трек доигрывается сам. Без `audioSession` (старый iOS) на тач-устройствах тикер подсказывает снять телефон с беззвучки.

## 7. Звук (Web Audio API)

Всё синтезируется, сэмплов нет. Каждая функция начинается с `if (!live()) return;`, где `live() = ctx && !muted`.

| Функция | Как сделано |
|---------|-------------|
| `fart(rev)` | sawtooth 70–140→35–60Hz (при `rev` — наоборот, вверх) + LFO 18–40Hz на частоту + lowpass 400–900Hz Q6, огибающая 0.35–1.1с |
| `sweep(type,f1,f2,dur,vol,vib?)` | базовый «свип» с экспоненциальной частотой и опциональным вибрато |
| `whistle()` | sine-свип вверх или вниз с вибрато 6–12Hz |
| `tone(type,freq,start,dur,vol)` | одиночная нота |
| `honk()` | два square-гудка |
| `robot()` | 5 triangle-нот (бип-буп ИИ) |
| `pew()` | двойной square-свип 1600→120 (пыщь-пыщь) |
| `laser()` | sawtooth-свип вниз (луч поноса) |
| `thud()` | sine 160→40 (удар печати) |
| `chord()` | три sawtooth-аккорда (инквизиция) |
| `theremin()` | два sine-свипа с вибрато (голактеко) |
| `musicBox()` | 12 triangle-нот на 3/4 (балет) |
| `clop()` | шумовой буфер `noise()` (генерируется один раз) через два bandpass (кокосы) |
| `ampNote()`, `ampDrum()`, `ampFx()` | инструменты секвенсора УПЧК-амп, пишут в `amp.gain` (§6.12) |
| `unlockAudio()` / `wake()` | создают и будят `AudioContext`, iOS-нюансы (§6.12) |
| `speak(text)` | `SpeechSynthesisUtterance`, `ru-RU`, случайные rate 0.8–1.6 и pitch 0–2, `%username%` → «юзернейм» |

Циклы: `loopSounds()` — случайный звук каждые 0.4–1.5с (из них пердёж 3/8), `loopSpeech()` — каждые 5–11с.
Пока играет УПЧК-амп, `loopSounds()` срабатывает в 15% случаев, а `loopSpeech()` молчит. Кнопка mute выставляет `muted`, вызывает `speechSynthesis.cancel()` и `ampStop()`; при снятии mute контекст будится через `wake()`.

## 8. Порядок старта

1. Сразу при загрузке, ещё до клика, запускаются визуальные циклы: летающий текст, эмодзи, счётчик, подзаголовок, лог, каменты, отзывы, заголовок вкладки.
2. Клик по кнопке в `#start` (клик по тексту дисклеймера ничего не делает):
   - `#calm` сначала ставит `body.calm` — офисный режим: `animation: none` на body и всём внутри, `shake()` и пульс `.center` молчат, звук и JS-полёты работают;
   - при `prefers-reduced-motion: reduce` дисклеймер показывает `#osCalm` и ставит фокус на `#calm`;
   - `unlockAudio()` создаёт `AudioContext` (iOS-нюансы — §6.12);
   - звучат пердёж и «великий онотоле! платформа ии ололо»;
   - +0.5с — `loopSounds`;
   - +2.5с — первое окно;
   - +3.5с — `loopSpeech`;
   - +6с — `loopStamps`;
   - +11с — `loopInterrupts`;
   - запускается интервал случайных окон (7с, 50%).

## 10. Известные проблемы и техдолг

1. ~~**`tick()` читает `offsetWidth` у каждой надписи на каждом кадре.**~~ Исправлено: ширина хранится в `f.w` и обновляется только при смене текста через `setFlyText(f, text)`. Весь код, меняющий текст надписи, должен идти через неё.
2. ~~**`body.shake` конфликтует с `body.popyach`.**~~ Исправлено: для `body.popyach.shake` есть отдельная анимация `shakeflip`, которая трясёт вместе с переворотом.
3. **Перевёрнутый режим.** Координаты клика (`clientX/Y`) не пересчитываются, поэтому лучи и взрывы рисуются в зеркальной точке.
4. **Таймеры никогда не очищаются,** а у каждого эмодзи свой `setInterval`. Это нормально, пока страница одна, но если появится «перезапуск хаоса», понадобится реестр таймеров.
5. **Мёртвый код в `musicBox()`:** выражение `(i % 3 === 0 ? 1 : 1)` ничего не делает.
6. **Олбанский не откатывается** для уже сгенерированных строк лога, каментов и открытых окон.
7. **Шрифт.** Comic Sans есть только на Windows и macOS. На Android и Linux подставляется что-то другое (в headless Chromium это был serif). Можно встроить Comic Neue как base64 woff2 в `@font-face`: файл вырастет примерно на 30–60 КБ, зато будет одинаково везде.
8. **Синтез речи на iOS Safari** иногда молчит в фоновых циклах (не из обработчика жеста). Голоса `ru-RU` зависят от ОС. Засыпание самого Web Audio на iOS уже лечится (§6.12), речь — нет.
9. ~~**Фоточувствительность.**~~ Частично исправлено: на старте дисклеймер в духе игровых предупреждений (серьёзный блок о припадках — без шуток и олбанского), офисный режим `body.calm` и подсказка при `prefers-reduced-motion`. Исходная заметка: мигание в `blink .2s`/`.25s steps(2)` даёт примерно 2–2.5 вспышки в секунду, это под порогом WCAG (3/с). При добавлении эффектов держать вспышки не чаще 3 раз в секунду. Стоит подумать о строчке-предупреждении на стартовом экране и о режиме `prefers-reduced-motion`, который отключает мигание и тряску.
10. **Доступность** сознательно принесена в жертву (это шутка), но у кнопок есть `type="button"`, а у пепякомэна — `aria-hidden`.

## 11. Контент-гайдлайны лора

- **Можно:** весь безобидный глоссарий Упячки (УГ, глагне, попячтсо, пыщь, лучи поноса, пепяка, стопицот, котэ, ПЯНИ, ЖЪРЧИК…), мемы про Онотоле в канонической хвалебной гиперболе (великий, знает всё, 7 мозгов, одобряе/негодуе), жаргон падонкафф, Монти Пайтон, переделанный под платформы, мат в рамках мемов.
- **Онотоле — реальный человек** (Анатолий Вассерман). Используем только устоявшийся мем-образ и его хвалебный формат. Не выдумываем ему цитат и не пишем ничего порочащего.
- **Не берём:** упячечные прозвища политиков, мемы про конкретных частных людей, падонковские «выпей йаду» и «убейся апстену».
- **Не рисуем чужих персонажей и картинки** (медведа из «Превед», оригинальные упячечные гифки, ногу Гиллиама и т.п.). Только эмодзи, CSS и собственный SVG. Тексты мемов при этом — пожалуйста.
- **Цитаты из фильмов** — только короткие крылатые фразы. Тексты песен не вставляем.

## 12. Как добавлять типовые штуки

**Новый мем** — дописать строку в нужный массив (§5).

**Новое окно:**
```js
// в STATIC_POPUPS
["🦖", "Текст окна", ["КНОПКА1", "КНОПКА2"], "special?"],
```

**Новая вставка:**
1. Добавить ветку в `interrupt()`.
2. Добавить CSS `.interrupt.<kind>`.
3. Добавить `kind` в `pick([...])` внутри `interrupt()`.
4. При желании — `special` для окна.

**Новый трек УПЧК-ампа** — дописать объект в `TRACKS` (§5, формат партий в §6.12). Мелодии только свои: от чужих песен берём максимум название-мем, ноты чужих мелодий и тексты песен не переносим (§11).

**Новый звук:** функция с `if (!live()) return;`, собрана на `sweep()` или `tone()`. Чтобы звучала в фоне — добавить в `pick` внутри `randomSound()`.

**Новая кнопка-режим:**
1. `<button class="X" id="X" type="button">` внутри `.controls`.
2. Стиль `.controls .X`.
3. Обработчик в JS.
4. Если это режим — класс на body.
5. На телефоне кнопки переносятся автоматически. Если рядов станет больше двух, увеличить `bottom` у `.controls` в медиазапросе ≤700px.

**Новая анимация.** CSS-анимации в офисном режиме `body.calm` выключаются сами. Всё, что двигается из JS (`element.animate()`, тряска, мигание таймером), должно само проверять `document.body.classList.contains("calm")`. Иначе человек, который попросил без вспышек, их получит.

**Стартовый дисклеймер.** Абсурд — вокруг, а блок `.serious` остаётся серьёзным: без шуток, без олбанского, с советом закрыть вкладку при симптомах.

## 13. Предлагаемая структура репозитория для дальнейшей разработки

Если файл начнёт расти, разработку можно вести в исходниках, а на выходе собирать тот же один HTML:

```
src/
  index.html        — разметка с плейсхолдерами /*CSS*/ и /*JS*/
  styles.css
  js/
    utils.js  lore.js  olbanize.js  generator.js
    audio.js  flyers.js  effects.js  popups.js  interrupts.js  main.js
build.mjs           — склеивает JS в IIFE и инлайнит в src/index.html → dist/index.html
tests/smoke.py      — playwright smoke-тест
```

Сборку можно сделать без зависимостей: `node build.mjs` читает файлы и делает `String.replace` плейсхолдеров. Минификация не нужна.

## 14. Smoke-тест (Playwright)

Тест лежит в `tests/smoke.py`:

```bash
pip install playwright && playwright install chromium
python3 tests/smoke.py
```

Он открывает `index.html` на 1440×900, 390×844 и 844×390, жмёт `#go` на стартовом дисклеймере, потом `#olb`, `#beams`, `#walk`, `#gen`, `#disco`, проверяет, что в консоли нет ошибок, и кладёт скриншоты в `tests/*.png`. Второй проход стартует через `#calm` и проверяет, что в офисном режиме не осталось ни одной CSS-анимации.

Важно: все клики по анимированным элементам делать с `force=True`, иначе Playwright ждёт «стабильности» элемента бесконечно.

Ручная проверка на iPhone (Playwright не повторяет аудиостек iOS): дисктоячка играет в беззвучном режиме, после сворачивания Safari и возврата трек доигрывается по тапу, марш с речью не замолкает.
